START HERE — Unbound Keyboard for your computer
===============================================

1. Unzip this. Put the folder on your Desktop.
   Do not double-click anything from inside the zip.
2. Open the folder.
3. Double-click  Try-Unbound-Keyboard.bat
   If you only see a Windows folder, open that first, then
   double-click Try-Unbound-Keyboard.bat.
4. First time takes about a minute. Leave the window open.
   If Windows shows a blue box: More info → Run anyway.
5. When the card opens, type:

     I recieve this and should of said thanks just just just

6. Click Fix spelling, or tap a yellow chip. Leave it if you meant
   what you typed. Then try Put this where I was typing.

Tray → Unbound Keyboard, or Ctrl+Shift+U, opens the card any time.

This try-it copy may not be signed in yet. Spelling still works.
On the card, type your email, tap Send a sign-in note, paste the
slip from your mail, tap Sign in. The website box is the Heirloom
page in your browser (https://…) — not a street address. Leave it
blank if you only want spelling here. We never ask for a Google,
Microsoft, Windows, or phone password.

MAC
---
Double-click run.sh in this folder (or in the Windows folder).

ANDROID PHONE
-------------
The phone keyboard is a separate file: UnboundKeyboard.apk
Copy it to the phone and tap it. Then Settings → System →
Languages & input → On-screen keyboard → Unbound Keyboard.

IPHONE
------
Apple does not let us install this keyboard. Use Write inside
the Heirloom app instead.
